# QR Code Card

## About the Project

This is a beginner-friendly frontend project that displays a QR code card using HTML and CSS. The card contains a QR code, a heading, and a short description encouraging users to improve their frontend development skills.

## Technologies Used

* HTML5
* CSS3

## Features

* Simple card layout
* Rounded corners and box shadow
* Centered text
* Custom background and styling

## Project Structure

* `index.html` – Defines the webpage structure.
* `index.css` – Styles the QR code card.
* `QR-code.png` – Image displayed inside the card.

## What I Learned

* Creating webpage structures using HTML.
* Connecting an external CSS file to HTML.
* Using CSS properties such as margins, borders, border-radius, text alignment, and box-shadow.
* Arranging elements to create a simple card design.

## How to Run

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in a web browser.

## Future Improvements

* Make the card responsive for different screen sizes.
* Improve spacing and typography.
* Add hover effects and refine the design.
